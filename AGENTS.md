# Evolution Lab contributor guidance

This repository contains game experiments in separate folders. Immunity lives in `immunity/`.

Before editing Immunity, read [its contributor guidance](immunity/AGENTS.md), [wiki index](immunity/docs/index.md) and [project state](immunity/docs/project-state.md). Run its package commands from `immunity/`. Its existing preservation and verification rules apply throughout that project.

Preserve existing Git history, unrelated work, anonymous score identities, learned genomes and local runtime data. Keep each game's dependencies and hosting configuration within its own directory. The sibling Enter-the-pygame repository is independent of this repository.
